# Adopt MetalUI C27 (material follow-ups) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt MetalUI C27 (master `848ee029`, PR #76, record §101), closing gaps C21-a and C21-b: the glass solve reads the material's tint opacity from MetalUI's public `Material.tint(in:)` instead of a copied table, and the app honours Reduce Transparency through MetalUI's `\.accessibilityReduceTransparency`, proven by headless window tests.

**Architecture:** `GlassThickness.materialOpacity(isDark:)` keeps its signature and becomes a read of `material.tint(in:)`, so `GlassStyle.tint` (the solve `t = 1 - (1 - g) / (1 - m)`, in `tintOpacity(glass:materialOpacity:)`) and every caller are unchanged. For Reduce Transparency MetalUI does the material half (every material is an opaque grey rect, never a backdrop record, divergence 315); the app's half is that `GlassPanel` and the two chips read `@Environment(\.accessibilityReduceTransparency)` and pass it to `GlassStyle(reducesTransparency:)`, which already exists and makes the theme's tint opaque. The material layer is always drawn now (MetalUI owns the fallback), so `GlassStyle.blursBackdrop` goes. No new type, no new target, no `Package.swift` change.

**Tech Stack:** Swift 6.4 strict concurrency, Swift Testing, MetalUI at `../MetalUI` master `848ee029` or later (`Material.tint(in:)`, `EnvironmentValues.accessibilityReduceTransparency`, `HeadlessPlatformWindow.Options.accessibilityReduceTransparency`, `TestWindow.setReduceTransparency(_:)`), SwiftLint.

## User decisions

**U-C27-1. What the glass panels' theme tint does when Reduce Transparency is on.** MetalUI's own material fallback (an opaque grey, light 0.925 / dark 0.2248 for `.ultraThin`) is relied on for the material, as asked: the plan draws the material layer always and leaves the grey to MetalUI. The open product choice is the theme tint layer drawn over that grey. Note the tension with "rely on MetalUI's fallback": under A the tint is fully opaque, so MetalUI's grey is completely covered and never seen; **B is the only option where MetalUI's fallback is what the user sees** (C shows it partly). A still relies on MetalUI for the no-blur, no-backdrop-copy half, which is what makes the setting cheap.

- **A (recommended, this plan): the tint goes fully opaque** (`fill.opacity(1)`: Dracula's `#21222c`, Alucard's light glass, Nord's). The panel is exactly the colour the theme's text was designed against, the grey underneath is invisible, and the look is the same on every surface and thickness. Cost: it is the theme colour, not the system's neutral grey.
- B: the tint is dropped (opacity 0): the panel is MetalUI's neutral grey. Closest to what a SwiftUI app shows; loses the theme's identity, and a custom theme's text colours were never chosen against that grey. One-line change: `GlassStyle.tint`'s first line returns `fill.opacity(0)` (and `reducingTransparencyMakesTheThemesColourOpaque`, `reducingTransparencyKeepsEveryThemesTextLegible` and `withTheSettingOnEveryPanelIsTheThemesGlassColourAtFullOpacity` change to the grey).
- C: leave the tint at its derived opacity (about 72% for Dracula) over the grey. Zero app code; the result is opaque but a theme-editor edit of the Glass role's opacity changes the shade (at 40% the panel is mostly neutral grey), so legibility depends on a slider. One-line change: delete the guard in `GlassStyle.tint`.

Why A: it is an accessibility setting, so predictability beats fidelity to the translucent look, and A is the one choice whose legibility is provable per theme (`reducingTransparencyKeepsEveryThemesTextLegible`). The plan's code is for A; B and C are the one-line changes above.

```swift
import CreatorStyle
import MetalUI
import Testing

/// `GlassThickness.materialOpacity(isDark:)` reads MetalUI's `Material.tint(in:)` (MetalUI C27, gap C21-a). The glass solve
/// `t = 1 - (1 - g) / (1 - m)` assumes `m` is what the material really composites over its blur, so this renders each
/// material and reads the opacity of the backdrop record MetalUI draws: the tint API and the drawing agree. It guards no
/// copy of a table; MetalUI's own `MT-B` tests pin the API, and human check MT-3 covers the solve against a real window.
@MainActor
struct GlassMaterialOpacityTests {
    func backdropOpacity(_ thickness: GlassThickness, _ scheme: ColorScheme) throws -> Float {
        let scene = renderHeadless {
            ZStack {}.frame(width: Pixels(80), height: Pixels(40)).background(thickness.material)
                .environment(\.colorScheme, scheme)
        }
        return try #require(scene.backdrops.first).tint.a
    }

    @Test(arguments: GlassThickness.allCases, [true, false])
    func theOpacityTheSolveUsesIsTheOneTheMaterialIsDrawnWith(_ thickness: GlassThickness, _ isDark: Bool) throws {
        let drawn = try backdropOpacity(thickness, isDark ? .dark : .light)
        let read = thickness.materialOpacity(isDark: isDark)
        #expect(abs(Double(drawn) - read) < 1e-4, "\(thickness) \(isDark ? "dark" : "light"): drawn \(drawn), read \(read)")
    }
}
```

```swift
import CreatorGeometry
import CreatorStyle
import CreatorViewport
import MetalUI
import MetalUITesting
import Testing
@testable import CreatorApp
@testable import CreatorEditor
@testable import CreatorSketchEditor

/// Reduce Transparency through real headless windows (MetalUI C27, gap C21-b): `HeadlessPlatformWindow.Options` starts a
/// window with the setting on and `TestWindow.setReduceTransparency(_:)` flips it while the window runs. With it on,
/// MetalUI draws every material as an opaque grey rect and never a backdrop record (divergence 315), each glass panel
/// lays the theme's glass colour over it at full opacity (`GlassStyle.tint`), and the text is still drawn; with it off the
/// frame is the C21 frame. The panels are counted by the backdrop records of the setting-off frame, not by a number written
/// here, so a new default panel needs no edit. How the grey and the opaque colour look in a real window is human check C21-5.
@MainActor
struct GlassReduceTransparencyWindowTests {
    static let reducing = HeadlessPlatformWindow.Options(accessibilityReduceTransparency: true)

    func hsla(_ colour: HexColor) -> [Float] {
        let value = colour.hsla
        return [value.h, value.s, value.l, value.a]
    }

    func isClose(_ a: [Float], _ b: [Float]) -> Bool { zip(a, b).allSatisfy { abs($0 - $1) < 0.01 } }

    /// Every rect's background, so two frames compare without `MUIRect` being `Equatable`.
    func backgrounds(_ scene: Scene) -> [[Float]] {
        scene.rects.map { [$0.background.h, $0.background.s, $0.background.l, $0.background.a] }
    }

    /// How many rects of the scene are filled with `colour`.
    func count(_ scene: Scene, _ colour: HexColor) -> Int {
        backgrounds(scene).filter { isClose($0, hsla(colour)) }.count
    }

    @Test func withTheSettingOnNoPanelOfTheAppBlurs() async throws {
        let on = try await AppWindow.open(options: Self.reducing).window.scene
        let off = try await AppWindow.open().window.scene
        #expect(on.backdrops.isEmpty, "MetalUI draws a material as a plain rect, never a backdrop record")
        #expect(!off.backdrops.isEmpty, "with the setting off the panels blur as before")
    }

    @Test func withTheSettingOnEveryPanelIsTheThemesGlassColourAtFullOpacity() async throws {
        let on = try await AppWindow.open(options: Self.reducing).window.scene
        let off = try await AppWindow.open().window.scene
        let opaque = GlassStyle(theme: .dracula, surface: .graphPanel, reducesTransparency: true).tint
        let translucent = GlassStyle(theme: .dracula, surface: .graphPanel).tint
        #expect(opaque.opacity == 1)
        // One tint rect per glass surface drawn, and a surface is a backdrop record when it blurs.
        #expect(count(on, opaque) == off.backdrops.count, "each panel's glass is the theme's colour, opaque")
        #expect(count(on, translucent) == 0, "the see-through tint is gone: nothing is left to see through it")
    }

    @Test func withTheSettingOnTheTextIsStillDrawnAndNothingIsDropped() async throws {
        let on = try await AppWindow.open(options: Self.reducing).window.scene
        let off = try await AppWindow.open().window.scene
        #expect(!on.glyphs.isEmpty)
        #expect(on.glyphs.count == off.glyphs.count, "every label is drawn with the setting on, as with it off")
    }

    @Test func withTheSettingOffTheFrameIsTheBlurringOne() async throws {
        let off = try await AppWindow.open(options: .init(accessibilityReduceTransparency: false)).window.scene
        let style = GlassStyle(theme: .dracula, surface: .graphPanel)
        #expect(!off.backdrops.isEmpty)
        #expect(count(off, style.tint) > 0, "the tint is the derived see-through one")
        #expect(off.backdrops.allSatisfy { abs(Double($0.tint.a) - style.thickness.materialOpacity(isDark: true)) < 1e-4 })
    }

    @Test func theSettingFollowsTheSystemWhileTheAppRunsInBothDirections() async throws {
        let app = try await AppWindow.open()
        let before = backgrounds(app.window.scene)
        let panels = app.window.scene.backdrops.count
        #expect(panels > 0)
        app.window.setReduceTransparency(true)
        let opaque = GlassStyle(theme: .dracula, surface: .graphPanel, reducesTransparency: true).tint
        #expect(app.window.scene.backdrops.isEmpty)
        #expect(count(app.window.scene, opaque) == panels)
        #expect(backgrounds(app.window.scene) != before)
        app.window.setReduceTransparency(false)
        #expect(app.window.scene.backdrops.count == panels)
        #expect(backgrounds(app.window.scene) == before, "switched back off, the frame is the original one")
    }

    @Test func thePaletteIsOpaqueToo() async throws {
        let app = try await AppWindow.open(options: Self.reducing)
        app.window.hover(at: app.point(inCanvasView: Vector2(200, 40)))
        app.window.typeKey(.space)
        try await app.window.runUntilIdle()
        #expect(app.palettePanel != nil, "the palette opened")
        #expect(app.window.scene.backdrops.isEmpty)
        let palette = GlassStyle(theme: .dracula, surface: .palette, reducesTransparency: true).tint
        #expect(count(app.window.scene, palette) > 0)
    }

    func chipScene(_ options: HeadlessPlatformWindow.Options) throws -> Scene {
        let chip = try #require(ReadoutChip(text: "12.5 mm", pointer: ScreenPoint(300, 200),
                                            in: ViewportSize(width: 700, height: 500), measuring: .fake))
        let window = try TestWindow(options: options) {
            ZStack(alignment: .topLeading) { ReadoutChipView(chip: chip) }
                .frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .topLeading)
        }
        return window.scene
    }

    @Test func theSketchChipsFollowTheSettingToo() throws {
        let on = try chipScene(Self.reducing)
        let off = try chipScene(.init())
        #expect(on.backdrops.isEmpty && off.backdrops.count == 1)
        #expect(count(on, GlassStyle(theme: .dracula, surface: .chip, reducesTransparency: true).tint) == 1)
        #expect(!on.glyphs.isEmpty && on.glyphs.count == off.glyphs.count)
    }
}
```
