# KI-1: KiCad board import — the board — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Import KiCad Board node that reads any `.kicad_pcb` (KiCad 4 to 11) into a board solid with its outline, drilled holes and
mounting holes, on a wire, with names that picks follow.

**Architecture:** A new portable module `CreatorPCB` (S-expression reader, board reader, outline chainer, identity keys; no kernel, no
graph) feeds `ImportKiCadBoardNode` in `CreatorNodes`, which extrudes the outline and cuts every hole with one `Kernel.place` and one
`Kernel.boolean`. The board file is a linked `ConstantValue.pcbFile`, stamped by the evaluator like Import Mesh's file. Components are KI-2.

**Tech Stack:** Swift 6.4 (strict concurrency), Swift Testing, OpenCascade through `Kernel`, MetalUI app shell.

**Spec:** `docs/superpowers/specs/2026-11-15-kicad-import-design.md` (sections Behaviour, Reading the board, Names that picks follow,
Limits, Construction, KI-1). KiCad's own behaviour, with source references: `docs/superpowers/specs/2026-11-16-kicad-format-facts.md`.

Rules (spec "Reading the board", facts §3, §5, §6, §8, §9):
- Refuse a file starting with `PCBNEW-BOARD` (legacy `.brd`) with the spec's sentence; a top list that isn't `kicad_pcb` → "This isn't a
  KiCad board file."
- `footprint` and `module`; reference from `(property "Reference" …)` else `(fp_text reference …)`; uuid from `uuid` else `tstamp`.
- Footprint place: `(at x y a)`, or from 20260616 `(transform (translate x y) (rotate a) (scale sx sy))` (a scale not positive and finite
  is 1). Graphics and pad positions are local: `place.apply(local)` (with y negated first). Pad angle in the file is absolute for
  `(at …)` footprints; for `transform` footprints it is library-frame, so absolute = pad angle + place angle (ruling, unconfirmed in
  KiCad source; pinned by a test so a later correction is one line).
- Drill: `(drill d)`, `(drill oval w h)`, each optionally `(offset dx dy)`, the offset in the pad's frame (turned by the pad's absolute
  angle). An oval's long axis is the pad's x when w ≥ h, else its y (angle + 90). Pads with no drill or a drill of 0 make no hole. `np_thru_hole` → `isPlated = false`.
- Back footprints: positions and angles are read as stored (already flipped by KiCad); `isBack` only matters for models (KI-2).
- Old forms by version (facts §5): arcs ≤ 20210925 as centre/start/angle (convert to start/mid/end: mid is the start turned by angle/2;
  in y-up coordinates a positive file angle turns clockwise, so negate it); model `(at (xyz))` × 25.4, `(offset (xyz))` as is.
- `gr_rect`/`fp_rect` → 4 lines; `gr_poly`/`fp_poly` `(pts (xy …) (arc (start)(mid)(end)) …)` → lines and arcs, closed; `gr_curve`/
  `fp_curve` → bezier. Only items on layer `Edge.Cuts` (`(layer "Edge.Cuts")` or bare atom). Flags: `(hide)`, atom `hide`, `(hide yes)`.
- Vias: `(via (at x y) (size s) (drill d) … (uuid …))` → round, plated, identity filled later.
- Thickness `(general (thickness t))`, else sum of `(setup (stackup (layer … (thickness t))))`, else nil. Copper layers: count of
  `(layers …)` entries whose canonical name ends in ".Cu".
- Counts against limits as reached: footprints, pads.

Rules: arcs from three points (centre by perpendicular bisectors; direction from the turn sign of start→mid→end; `Segment2D.arc` with
`end < start` for clockwise, `end − start = 2π` for a full circle); a three-point arc whose points are collinear within 1e-9 becomes a line.
Bézier → one degree-5 `SplineCurve2D` (knots [0, 1], multiplicities [6, 6]) by degree elevation (cubic → quartic → quintic, exact).
Chaining: pieces joined end to end within `tolerance` (Euclidean), reversing pieces as needed; where two ends differ by more than 1e-9
a line's end is moved onto the other piece's end; between two curved pieces a joining line is inserted. A loop needs every piece
used once; loops are closed. Loop with the largest absolute area = outer (counter-clockwise), the others holes (clockwise) and must
lie inside it. Refusals (sentences, coordinates `Double.display` in KiCad's y-down sense, i.e. y negated back): "The board has no
outline on Edge.Cuts.", "The board outline isn't closed near (x, y) mm.", "The board outline crosses itself near (x, y) mm.",
"A cutout lies outside the board outline near (x, y) mm.". Ordering (spec Names that picks follow): holes sorted by their lowest key;
each loop starts at its lowest-keyed segment, keeping its direction.
