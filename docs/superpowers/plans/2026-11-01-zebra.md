# Zebra Stripes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zebra stripe view mode that draws reflection stripes on every shown part, on Metal and SDL GPU, with the
four-control panel, a lock, and finer display meshes while it is on.

**Architecture:** `ZebraSettings` is view state in CreatorGraph (like `SectionSettings`). The viewport takes a
`ViewportZebra` through `ViewportModel.showZebra(_:)` and draws non-ghost items with a third surface pipeline
(`zebra_mesh`, beside `mesh` and `field_mesh`) on both renderers; a CPU twin of the stripe function pins the shaders.
`Kernel.tessellate` gains an angular deflection, and the viewport tessellates at 0.05 rad while zebra is on. The app wires
the toggle, menu, key, panel and lock.

**Tech Stack:** Swift 6.4, Swift Testing, MetalUI, Metal (MSL at run time), SDL GPU (HLSL compiled by
`scripts/build-shaders.sh`), OpenCascade 7.9 C shim.

**Spec:** `docs/superpowers/specs/2026-11-01-zebra-design.md`

## Global Constraints

- View state only: no command, no undo step, no edited dot; saved as the optional `ViewState.zebra` key, no format bump.
- Stripes: count 4 to 40, default 12, `count` periods over the full turn of the reflection's angle; black share 20 % to
  80 %, default 50 %; Direction Horizontal or Vertical; Lock off by default.
- Finer display mesh while zebra is on: angular deflection **0.05 rad** (normal: 0.5 rad), linear deflection unchanged.
- Ghosts are never striped; sketch mode hides zebra; zebra beats the field tint (the legend stays); the section clip
  applies to striped faces.
- MSL (`Sources/CreatorViewport/Render`), HLSL (`Shaders/viewport`, `common.hlsli`) and the Swift GPU structs change
  together; `GPUDataTests` and `ShaderSourceTests` pin them. HLSL members are `float4`/`uint4`/scalars, never `float3`.
- OCCT only behind `Kernel`, under `OCCTKernel.serialized`; the shim stays portable.
- Swift Testing; `swiftlint lint --strict` 0; 12 "Test run with" lines on macOS and Linux; only the known
  `HLSLEngineTests.onTheCutTheHLSLEngineAgreesWithTheMetalEngine` failure.

## Review Focus

1. **Perspective and orthographic:** the reflection uses the per-pixel view vector in perspective; stripes must not be
   identical to the orthographic picture there. Test in Task 3 (`perspectiveStripesUseThePixelsViewVector`).
2. **Toggling quickly:** turning zebra on and off while a tessellation runs ends with meshes at the final angle. Test in
   Task 5 (`theLastToggleWins`).
3. **Lock survives reopening:** a locked file reopens with the same lock frame. Tests in Task 1 (round trip) and Task 6
   (`lockCapturesTheCameraAndReopens`).
4. **Zebra with the section:** clipped faces are discarded and a back face seen through the cut is striped with the
   flipped normal, not darkened. Task 3 (`theClipStillCutsAStripedPart`).
5. **Zebra over a tinted item:** the zebra pipeline wins. Task 3 (`zebraBeatsTheFieldTint`).

## Rulings

1. **The stripe function** (the CPU twin and both shaders, exactly):
   - Unlocked, in view space (camera looks down −Z): `n` the interpolated normal renormalized (flipped on a back face),
     `v` the unit vector toward the eye (`(0,0,1)` orthographic, `−normalize(viewPosition)` perspective),
     `r = 2(n·v)n − v`; components `(rx, ry, rz) = (r.x, r.y, r.z)`.
   - Locked, in world space: `n` the world normal, `v = lock.toEye`, `r` as above;
     `(rx, ry, rz) = (r·lock.right, r·lock.up, r·lock.toEye)`.
   - Angle: Horizontal `θ = atan2(ry, rz)`, Vertical `θ = atan2(rx, rz)`. Phase `p = θ · count / 2π`.
   - Band: black when `fract(p) < blackShare`. Shaders antialias the two edges over `fwidth(p)` with `smoothstep`; the
     CPU twin returns the hard value (tests sample away from edges).
   - Colour: white `shade.light`, black `shade.dark × 0.15`, then × `(0.8 + 0.2 × key)` with the existing key light, then
     the existing hover, selection and warning mixes. Alpha 1.
2. **The lock frame** is the live pose's `(right, up, toEye)` when Lock is ticked, stored in world space as three
   `Vector3`s.
3. **Zebra and the tint:** when the frame has a zebra, a non-ghost item takes the zebra pipeline even if it has field
   values; nothing else changes in the field preview.
4. **The finer mesh** replaces the normal one in the tessellation cache (not a second cache); a solid keeps drawing its
   old mesh until the new one lands.
