# Adopt MetalUI C8 (the app shell) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the four M6 stopgaps with MetalUI C8's app shell (merged as MetalUI `70e9389`, PR #61): the close and quit veto with a Save / Don't Save / Cancel alert (M6-b), the window title, edited dot and proxy icon (M6-a), the hidden title bar with the top bar clearing the window buttons (M6-c), and Finder, Dock and `open` opening the document (M6-d).

**Architecture:** Behaviour lives in `@MainActor @Observable AppModel` and a few small pure types, all testable headless: `CloseDecision` (what to reply to a close request, whether the window closes after each answer), `AppModel.closeRequested()` / `answerSaveChanges(_:)`, `WindowChromeSync` (pushes `AppModel.windowChrome` into a `WindowChrome`, which MetalUI's `Window` already is), `AppModel.openRequested(_:)` and `AppLayout.topBarClearance(titleBarInsets:)`. `Sources/MetalCreatorApp/main.swift` only wires MetalUI's `Window` and `App` to them. MetalUI has no public headless window or platform (gap M6-e), so that wiring is checked by the human group AS.

**Tech Stack:** Swift 6.4 strict concurrency, Swift Testing, MetalUI at `70e9389` (`Window.onCloseRequest`, `replyToCloseRequest`, `title`, `isDocumentEdited`, `representedURL`, `windowStyle: .hiddenTitleBar`, `@Environment(\.titleBarInsets)`, `App.onOpenURL`, `App.open(_:)`), Swift's `Observations`.

**Spec:** `docs/superpowers/specs/2026-10-07-metalcreator-vertical-slice-design.md` §6.1 (app shell, the glass top bar under the traffic lights), §11 (packaging, document types) and its Errata (M6), (Packaging); `docs/metalui-gaps.md` entries M6-a, M6-b, M6-c, M6-d; `docs/superpowers/specs/2026-10-09-packaging-design.md` decisions 3 and 8. MetalUI's rulings: `../MetalUI/docs/superpowers/2026-10-08-app-shell-decisions.md` (AS-A…AS-Q, final spellings table at its top), `../MetalUI/docs/record/87-app-shell.md`, divergences 175 and 176, `../MetalUI/docs/packaging.md` ("Documents and URLs an application opens") and the probe `../MetalUI/docs/probes/appkit-open-without-document-class.swift`.

## Review Focus

Failure modes the spec implies and the tasks' main tests do not name, most likely first. Each has its test in the task that owns the code (or is named as human-only).

1. **A typed but uncommitted inspector value, then close.** Someone types 75 into Width and presses ⌘W: they expect the Save question, not a silent exit. The model commits the pending entry before it decides. Tests: `AppModelCloseTests.aTypedButUncommittedValueCountsAsAChange` (Task 1) and, for a Finder open, `AppModelOpenURLTests.aTypedButUncommittedValueIsKeptByAskingFirst` (Task 3).
2. **Save As cancelled, or the write fails, from the alert.** The window must stay and the changes must survive; a failure shows its own alert. Tests: `aCancelledSaveAsKeepsTheWindowAndTheChanges`, `aFailedSaveKeepsTheWindowAndShowsWhy` (Task 1).
3. **A second question while one is up.** ⌘Q or ⌘W again, New, Open… or a Finder open while the Save sheet is showing must not open a second sheet or orphan MetalUI's pending close request (which only `close()` could then end). Tests: `aSecondRequestWhileAskingKeepsTheFirstAlert`, `newAndOpenWaitWhileTheCloseQuestionIsUp`, `aRepeatedAnswerRepliesOnlyOnce`, `nothingOpensWhileTheCloseQuestionIsUp` (Tasks 1, 3). If another alert takes the sheet's place while the question is open, the next close request puts the Save sheet back: `aRequestAfterAnotherAlertTookItsPlaceAsksAgain` (Task 1). `SaveChangesAnswerTests` pins the three buttons' labels, order and roles (Cancel is the cancel role, nothing is destructive). Escape answers Cancel through the alert's cancel button; that and the sheet itself are human check AS-1.
4. **Opening a file onto edited work.** Double-clicking the file that is already open must not reload it over unsaved edits; a URL that isn't a file, a file that can't be read and a missing file must show an alert or do nothing, never crash; a multi-file drop leaves the last file. Tests: `theFileThatIsAlreadyOpenIsLeftAlone` (edited and unedited), `aURLThatIsNotAFileIsIgnored`, `aFileThatCantBeReadShowsWhyAndKeepsTheDocument`, `aMissingFileShowsWhy`, `severalFilesInOneDropLeaveTheLastOpen` (Task 3).
5. **The window shows what the document says.** The edited dot must clear on save and on New, and the title must follow a Save As rename; `Observations` must push without anyone calling `apply()`. Tests: `aSavedDocumentShowsItsFileAndTheEditedDotFollowsTheChanges`, `newClearsTheFileAndTheDot`, `followingPushesChangesAsTheyHappen` (Task 2). Not headless: whether the hidden title bar leaves the window draggable (new gap C8-a), where the buttons really sit, and that `AppRoot` passes the window's real insets to `TopBar` (human checks AS-4, AS-5). Headless: `TopBarClearanceRenderTests` renders the bar and the sketch toolbar with a non-zero clearance and asserts the first glyph moves by exactly that much (Task 4).

## Decisions made in this plan

- **Quit uses the window's close handler; the app sets no `App.onTerminateRequest`.** MetalUI asks every window's `onCloseRequest` in turn when the app has no terminate handler (AS-C item 2), and MetalCreator has exactly one window, so ⌘Q, Dock ▸ Quit, logout and ⌘W are the same question with one alert, one `.later`, one reply (`Window.replyToCloseRequest`) and one state machine in the model (`CloseRequestState`). An app handler would decide alone (the window is then not asked), so the model would need a second reply route (`App.replyToTerminateRequest`) and a second pending state, tested twice, for no behaviour the person can see. The cost: the alert can't say "quit". Revisit with a second window (a document window per file) or a non-document window.
- **`Window.close()` and `Window.performClose()` are not called by the app.** ⌘W and the close button already run `performClose`; the Don't Save and saved answers reply `true`, which closes. Nothing needs the unasking `close()`.
- **Title, edited dot and proxy icon are set on `Window` properties from one observer (`WindowChromeSync`), not with `.navigationTitle` / `.navigationDocument` in the tree.** `isDocumentEdited` has no tree spelling, so one mechanism sets all three; it is testable with a recording `WindowChrome`; and the tree modifiers need a container root (divergence 120).
- **Open-document events use `App.onOpenURL`, not a tree `.onOpenURL`.** The model lives outside the tree, there is one window, and the catch-all needs no `StateDispatch` or routing. The handler is set before `app.run()` (a launch-time open arrives inside `run()`, AS-M, AS-Q). The path argument is handed to `app.open(_:)` (AS-G item 6), because AppKit delivers no command-line path.
- **An open onto edited work reuses the New and Open… question** ("Discard unsaved changes?", `DiscardAction.openURL`), not the new three-button one.
- **The glass bar does not move.** Its content is padded by `AppLayout.topBarClearance` so the document name and controls start right of the window buttons, which float over the bar's left end (spec §6.1). Every other layout number, `PanelPlacement` and the viewport's model area are unchanged, so no existing test moves.

## User decisions

Product behaviour the spec leaves open. Each is written into the plan at its recommended default; the other options are listed so the choice can be reversed without reading the tasks.

1. **Does the window ship with a hidden title bar?** The viewport's gestures cover the title-bar band and MetalUI drags the window only from an unclaimed press (AS-J), so the window may not be draggable by its top bar (gap C8-a). Options: (a) ship it only if human check AS-5 shows the window drags, as a separate commit (Task 4b); (b) ship it regardless; (c) keep the standard title bar until MetalUI answers C8-a. Recommended: (a). Written as (a); if AS-5 fails, drop the one `windowStyle:` line and M6-c stays open.
2. **A Finder open of the file that is already open** does nothing, edited or not, and never reloads from disk. Options: (a) do nothing; (b) reload when unedited, do nothing when edited; (c) reload when unedited, ask "Revert to the saved version?" when edited. Recommended: (a), as document apps bring the open document forward and never reload it silently. Written as (a), pinned by `theFileThatIsAlreadyOpenIsLeftAlone` for both cases.
3. **A typed but uncommitted inspector value when a Finder open arrives.** Options: (a) commit it first, so it counts as a change and the "Discard unsaved changes?" question appears (as closing does); (b) discard it silently. Recommended: (a). Written as (a) in `openRequested(_:)`. New and Open… (spec M6) still discard such a value without asking; making them commit it too is a one-line follow-up in `AppModel+Files.swift`, left out here because they predate this plan.
4. **The top bar keeps the name and "— Edited"** beside the window's edited dot. Under a hidden title bar the title bar draws no title, so the top bar is the only place the name shows (spec Errata (M6) asks for it). Options: (a) keep both; (b) drop "— Edited" from the bar and rely on the dot. Recommended: (a). Written as (a).
5. **Quit and close share one alert** that can't say "quit" (the app sets no `onTerminateRequest`, see Decisions above). Options: (a) one alert, one state machine; (b) an app terminate handler with its own wording and a second reply route. Recommended: (a) while the app has one window. Written as (a).
6. **An open onto edited work asks the New and Open… question** ("Discard unsaved changes?") rather than the three-button Save question. Options: (a) reuse that question; (b) the Save / Don't Save / Cancel sheet. Recommended: (a) now, (b) if the person expects Save there. Written as (a).

```swift
/// The close and quit decision (spec §6.1, gap M6-b), as pure functions: what to answer MetalUI's close request, and
/// whether the window then closes.
struct CloseDecisionTests {
    @Test func aDocumentWithoutChangesClosesAtOnceAndOneWithChangesAsks() {
        #expect(CloseDecision.reply(isEdited: false) == .now)
        #expect(CloseDecision.reply(isEdited: true) == .later, "the window waits for the alert's answer")
    }

    @Test(arguments: [
        (SaveChangesAnswer.save, true, true),
        (.save, false, false),
        (.dontSave, true, true),
        (.dontSave, false, true),
        (.cancel, true, false),
        (.cancel, false, false),
    ])
    func theWindowClosesOnlyAfterASaveThatWorkedOrADontSave(_ answer: SaveChangesAnswer, _ saved: Bool, _ closes: Bool) {
        #expect(CloseDecision.shouldClose(after: answer, saved: saved) == closes)
    }
}
```

Create `Tests/CreatorAppTests/AppModelCloseTests.swift`:

```swift
import CreatorEditor
import CreatorGraph
import CreatorNodes
import Foundation
import MetalUI
import Testing
@testable import CreatorApp

/// Closing the window and quitting with unsaved changes (spec §6.1, gap M6-b): the alert, each answer, and the one
/// reply the window gets. MetalUI's window and app are not built here (no public headless window, gap M6-e), so the
/// model's handler and reply are driven directly.
@MainActor
struct AppModelCloseTests {
    /// An app whose window replies are recorded.
    final class Replies {
        var values: [Bool] = []
    }

    func makeEditedApp(file: URL? = nil, picker: ScriptedPicker? = nil) async throws -> (AppModel, Replies) {
        let app = await makeApp()
        let replies = Replies()
        app.replyToCloseRequest = { replies.values.append($0) }
        app.filePicker = picker
        if let file { try app.save(to: file) }
        try app.document.perform(.addNode(BuiltInNodes.registry.makeNode(NumberNode.typeID)))
        #expect(app.isEdited)
        return (app, replies)
    }

    @Test func aDocumentWithoutChangesClosesAtOnceWithNoAlert() async {
        let app = await makeApp()
        #expect(app.closeRequested() == .now)
        #expect(app.alert == nil && app.closeRequest == .idle)
    }

    @Test func aDocumentWithChangesAsksAndTheWindowWaits() async throws {
        let (app, replies) = try await makeEditedApp()
        #expect(app.closeRequested() == .later)
        #expect(app.alert == .saveChanges(name: "Untitled"))
        #expect(app.alert?.title == "Do you want to save the changes to “Untitled”?")
        #expect(app.closeRequest == .asking)
        #expect(replies.values.isEmpty, "nothing is answered until the person answers")
    }

    @Test func theAlertNamesTheFile() async throws {
        let url = temporaryURL("bracket.mcgraph")
        defer { try? FileManager.default.removeItem(at: url) }
        let (app, _) = try await makeEditedApp(file: url)
        _ = app.closeRequested()
        #expect(app.alert == .saveChanges(name: url.lastPathComponent))
    }

    @Test func aTypedButUncommittedValueCountsAsAChange() async throws {
        var builder = GraphBuilder()
        let extrude = builder.solid(distance: 10).extrude
        let app = await makeApp(builder.graph)
        let id = extrude.id
        app.editor.notePendingEntry(PendingEntry(text: "25") { value in
            try? app.document.perform(.setInput(id, "distance", .number(value)))
        })
        #expect(!app.isEdited, "typed, not committed")
        #expect(app.closeRequested() == .later, "closing commits the typed value, which is a change")
        #expect(app.document.graph.nodes[id]?.inputValues["distance"] == .number(25))
    }

    @Test func aSecondRequestWhileAskingKeepsTheFirstAlert() async throws {
        let (app, _) = try await makeEditedApp()
        _ = app.closeRequested()
        #expect(app.closeRequested() == .later)
        #expect(app.closeRequest == .asking && app.alert == .saveChanges(name: "Untitled"))
    }

    @Test func aRequestAfterAnotherAlertTookItsPlaceAsksAgain() async throws {
        let (app, replies) = try await makeEditedApp()
        _ = app.closeRequested()
        app.alert = .problem(AppProblem("Something else failed", "It happened while the question was up."))
        #expect(app.closeRequested() == .later)
        #expect(app.alert == .saveChanges(name: "Untitled"), "without its buttons nothing could answer the close request")
        #expect(app.closeRequest == .asking)
        await app.answerSaveChanges(.dontSave)
        #expect(replies.values == [true])
    }

    @Test func saveWritesTheDocumentsFileThenClosesTheWindow() async throws {
        let url = temporaryURL("saved.mcgraph")
        defer { try? FileManager.default.removeItem(at: url) }
        let picker = ScriptedPicker([])
        let (app, replies) = try await makeEditedApp(file: url, picker: picker)
        _ = app.closeRequested()
        await app.answerSaveChanges(.save)
        #expect(replies.values == [true])
        #expect(!app.isEdited && app.alert == nil && app.closeRequest == .idle)
        #expect(picker.asked.isEmpty, "a titled document saves without a panel")
        let saved = try GraphFileIO.decode(Data(contentsOf: url), registry: BuiltInNodes.registry)
        #expect(saved.graph.nodes.count == 1)
    }

    @Test func saveOfAnUntitledDocumentRunsSaveAsAndClosesOnceItIsWritten() async throws {
        let url = temporaryURL("new.mcgraph")
        defer { try? FileManager.default.removeItem(at: url) }
        let picker = ScriptedPicker([url])
        let (app, replies) = try await makeEditedApp(picker: picker)
        _ = app.closeRequested()
        await app.answerSaveChanges(.save)
        #expect(picker.asked.map(\.name) == ["Untitled.mcgraph"])
        #expect(replies.values == [true])
        #expect(app.fileURL == url && !app.isEdited)
    }

    @Test func aCancelledSaveAsKeepsTheWindowAndTheChanges() async throws {
        let (app, replies) = try await makeEditedApp(picker: ScriptedPicker([nil]))
        _ = app.closeRequested()
        await app.answerSaveChanges(.save)
        #expect(replies.values == [false])
        #expect(app.isEdited && app.fileURL == nil && app.closeRequest == .idle)
    }

    @Test func aFailedSaveKeepsTheWindowAndShowsWhy() async throws {
        let missing = URL.temporaryDirectory.appending(path: "\(UUID().uuidString)/no/such/folder/x.mcgraph")
        let (app, replies) = try await makeEditedApp(picker: ScriptedPicker([missing]))
        _ = app.closeRequested()
        await app.answerSaveChanges(.save)
        #expect(replies.values == [false])
        #expect(app.isEdited)
        #expect(app.alert?.title == "“x.mcgraph” couldn't be saved")
    }

    @Test func dontSaveClosesAndLeavesTheFileAlone() async throws {
        let url = temporaryURL("kept.mcgraph")
        defer { try? FileManager.default.removeItem(at: url) }
        let (app, replies) = try await makeEditedApp(file: url)
        let before = try Data(contentsOf: url)
        _ = app.closeRequested()
        await app.answerSaveChanges(.dontSave)
        #expect(replies.values == [true])
        #expect(try Data(contentsOf: url) == before)
```

```swift
import MetalUI

extension AppModel {
    /// The window's `onCloseRequest` (close button, ⌘W, and ⌘Q, which asks each window in turn). With unsaved changes
    /// it shows the Save / Don't Save / Cancel alert and answers `.later`; the answer reaches the window through
    /// `replyToCloseRequest`. A typed but uncommitted inspector value counts as a change, so it is committed first. A request that arrives while
    /// the question is open answers `.later` again and puts the alert back if another alert replaced it.
    public func closeRequested() -> CloseRequestReply {
        guard closeRequest == .idle else {
            // A question is already open. If something else took the alert's place, ask again: MetalUI's close request
            // stays open until the model answers it, and without the buttons nothing could.
            if closeRequest == .asking, alert != .saveChanges(name: displayName) {
                alert = .saveChanges(name: displayName)
            }
            return .later
        }
        editor.commitPendingEntry()
        let reply = CloseDecision.reply(isEdited: isEdited)
        guard reply == .later else { return reply }
        closeRequest = .asking
        pendingDiscard = nil
        alert = .saveChanges(name: displayName)
        return reply
    }

    /// The alert's answer. Save runs the existing save flow (Save As… for an untitled document) and replies `true`
    /// only once it worked; a cancelled panel or a failed write replies `false`, and the failure's own alert shows.
    /// Only the first answer to a question counts.
    public func answerSaveChanges(_ answer: SaveChangesAnswer) async {
        guard closeRequest == .asking else { return }
        alert = nil

            if let filePicker { saved = await saveDocument(using: filePicker) }
        }
        closeRequest = .idle
        replyToCloseRequest?(CloseDecision.shouldClose(after: answer, saved: saved))
    }
}
```

```swift
/// Keeps a window's title, edited dot and represented file in step with the open document (gap M6-a): `follow()` runs
/// for the life of the window and pushes the model's `windowChrome` whenever it changes.
@MainActor
public final class WindowChromeSync {
    let model: AppModel
    let chrome: any WindowChrome

    public init(model: AppModel, chrome: any WindowChrome) {
        self.model = model
        self.chrome = chrome
    }

    /// Pushes what the model shows now; a value that is already shown is not written again.
    public func apply() {
        let state = model.windowChrome
        if chrome.title != state.title { chrome.title = state.title }
        if chrome.isDocumentEdited != state.isEdited { chrome.isDocumentEdited = state.isEdited }
        if chrome.representedURL != state.fileURL { chrome.representedURL = state.fileURL }
    }

    /// Applies the model's state now, then again after every change of it, until the task is cancelled.
    public func follow() async {
        let states = Observations { [model] in model.windowChrome }
        for await _ in states {
            apply()
        }
    }
}
```

```swift
import Foundation

extension AppModel {
    /// A file the system asks the app to open (gap M6-d): a Finder double-click, a drop on the Dock icon, `open -a`,
    /// and the path on `swift run MetalCreatorApp file.mcgraph`. MetalUI delivers it through `App.onOpenURL`.
    ///
    /// A URL that isn't a file, the file that is already open, and any URL while the close question is up are
    /// ignored. A typed but uncommitted inspector value counts as a change (it is committed first, as when closing).
    /// With unsaved changes it asks the New and Open… question first (`alert`, then `discardChanges()`);
    /// otherwise the file replaces the document, or an alert says why it couldn't be opened. Several files in one
    /// drop arrive one at a time, so the last one stays open.
    public func openRequested(_ url: URL) {
        guard url.isFileURL, closeRequest == .idle else { return }
        if let current = fileURL, current.standardizedFileURL == url.standardizedFileURL { return }
        editor.commitPendingEntry()
        guard !isEdited else {
            pendingDiscard = .openURL(url)
            alert = .discardChanges
            return
        }
        openReportingFailure(url)
    }

    /// Opens `url`, or shows why it couldn't be.
    func openReportingFailure(_ url: URL) {
        do {
            try open(url)
        } catch {
            alert = .problem(error)
        }
    }
}
```
