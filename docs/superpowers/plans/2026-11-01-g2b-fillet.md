# G-b2: Curvature-continuous fillets — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Curvature (G2) option on the Fillet node, with a tangency weight.

**Architecture:** OCCT builds the circular fillet; the shim replaces each strip face's surface with a skinned quintic-Hermite
surface matching the neighbours' position, tangent and curvature, and rebuilds corner patches with `BRepOffsetAPI_MakeFilling`.
Topology and tags are OCCT's, unchanged. **Task 1 is a gate:** if its measurements miss the tolerances, stop and report.

**Tech Stack:** Swift 6.4, Swift Testing, OpenCascade 7.9 (`BRepFilletAPI_MakeFillet`, `Geom_BSplineSurface`, `GeomAPI`/`GeomFill`,
`BRepOffsetAPI_MakeFilling`, `BRepLProp_SLProps`, `BRepCheck_Analyzer`).

**Spec:** `docs/superpowers/specs/2026-11-01-g2-surfacing-design.md` §G-b.

## Global Constraints

- OCCT only behind `Kernel`, under `OCCTKernel.serialized`; shim portable; no C++ exception into Swift; every allocation freed.
- Every blend result is checked by `BRepCheck_Analyzer`; an invalid result is never returned.
- Tolerances on every promised seam (spring seams only; strip-to-strip seams and open-end run-outs are not promised): position
  1e-4 mm, angle 0.01°, curvature within 1 % of the larger curvature or 1e-4 /mm, whichever is larger.
- Section: quintic Bézier, G2 Hermite at both ends; end tangent lengths `w × d` (`w` the weight, `d` the circular fillet's own
  end-tangent length for that section); the tangential component of each end's second derivative is zero.
- Weight 0.1…2.0, default 1.0. Continuity default Tangent (index 0); a missing input reads Tangent (no migration).
- Copy: strip failure "The fillet can't be made curvature continuous at this radius." (plus the largest radius sentence the blend
  errors already give); corner warning "N fillet corners are tangent only (G1)." (singular: "1 fillet corner is tangent only (G1).").
- Swift Testing; lint 0; 12 lines macOS and Linux.

## Review Focus

1. A fillet on an edge next to a cylinder (non-zero neighbour curvature) is G2 at both spring seams.
2. A tangent chain (line into arc) is filleted G2 without failing on its strip-to-strip seam.
3. Switching G1 → G2 → G1 keeps a downstream Edges by Tag pick on a blend face's edge.
4. A G2 fillet whose radius OCCT can build but whose strips miss the tolerance names the largest radius that passes.
5. Weight 0.1 and 2.0 both give valid solids on the plate edge (no self-intersecting section).
