> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the five MetalUI stopgaps that C10 (merged as MetalUI `2155f1e`) fixes: the inspector's slider coalescing (M5-a), the glass panels' blur and material (M5-c), the window background gradient (M5-d), the refused wire's shake (M5-i) and the evaluating badge's spinner (M5-j); mark each fixed in `docs/metalui-gaps.md`; say honestly what C10 could not give (M5-c).

**Architecture:** Four of the five are one-spot swaps behind a type of ours: `EditorModel.sliderEditingChanged(_:)` for `Slider(onEditingChanged:)`, `RefusalShake` plus a per-node `shakeCount` for `keyframeAnimator`, `StatusBadgeView` for `ProgressView`, a new `WindowBackground` component for `LinearGradient`. M5-c is a decision, not a swap: MetalUI's `Material` is a fitted grey tint with no backdrop blur and no theme, and `.blur(radius:)` blurs a view's own pixels, so `GlassPanel` keeps the theme's flat `glass` tint, a test pins that, and the missing backdrop blur is logged as the new gap C10-a. Behaviour stays in `EditorModel`; views stay thin. Motion is tested through MetalUI's public `KeyframeTimeline` at injected times and the spinner's still frame; what a running window does is human checks (group C10).

**Tech Stack:** Swift 6.4 strict concurrency, Swift Testing, MetalUI at `../MetalUI` (2155f1e: `Slider(onEditingChanged:)`, `keyframeAnimator`, `KeyframeTimeline`, `ProgressView`, `LinearGradient`), SwiftLint.

**Spec:** `docs/superpowers/specs/2026-10-07-metalcreator-vertical-slice-design.md` §6.1, §6.2, §6.4, §6.6 and its Errata (M5) (the stopgap bullets this plan rewrites), with all its Errata; the roadmap row "Adopt MetalUI C10"; `docs/metalui-gaps.md` M5-a, M5-c, M5-d, M5-i, M5-j. MetalUI's rulings are `../MetalUI/docs/superpowers/2026-10-08-controls-looks-decisions.md` `LK-A` to `LK-X` (record §85): the "Final spellings" table, `LK-U` (slider), `LK-V` (progress, keyframes), `LK-L` (materials) and `LK-X` (see Global Constraints).

## Review Focus

Inputs and conditions the spec implies and a person will hit, most likely first, each pinned by a test in the task that owns the code:

1. **Two slider drags back to back, with no selection change, canvas press or edit between them** must be two undo steps, not one merged step (Task 1, `twoDragsWithNothingBetweenThemAreTwoUndoSteps` and its parameter twin).
2. **A node refused twice in a row** must shake twice, and **refusing node A then node B** must shake only B (A's trigger is unchanged): the trigger is a per-node count (Task 3, `eachRefusalOfANodeAddsOneToItsCountAndNoOtherNode`).
3. **The refusal message timing out, or being cleared when the user starts another edit,** must not shake the node again, which it would if the trigger fell back to zero (Task 3, `aCountNeverGoesDownSoClearingTheMessageDoesNotShakeAgain`).
4. **A refused node that was culled off-screen and scrolls into view** must be drawn at rest, where it belongs, not offset (Task 3, `aRefusedNodeIsDrawnAtRestWhereItBelongs`).
5. **A node that is not evaluating** (idle, no state, ok, warning, error) must never show a spinner, and the spinner must fit the 24-pt node header (Task 2, `everyOtherStateDrawsTextAndNoSpinner`, `aQuietBadgeDrawsNothingVisible`, `theSpinnerFitsTheNodeHeader`).
6. **A non-Dracula theme** (Alucard's light glass, Nord's gradient) must reach the glass fill and the window gradient: neither may hard-code Dracula (Task 4, `aSelectedThemeIsTheOneDrawn`; Task 5, `theGlassColourFollowsTheTheme`).

import MetalUI

/// The refused edit's shake (spec §6.2): the refused node jumps 6 points right, 6 left and back to rest in a fifth of a
/// second. The keyframes are MetalUI's (gap M5-i, `keyframeAnimator`); `NodeView` runs them each time the node's
/// `EditorModel.shakeCount(of:)` goes up, and tests read the same timeline at a time of their choosing, so the motion is
/// pinned without a clock.
enum RefusalShake {
    /// How far the node moves to each side, in canvas points.
    static let distance = 6.0

    /// The offset's keyframes: out, across, home.
    @KeyframesBuilder<Double>
    static var keyframes: some Keyframes<Double> {
        KeyframeTrack {
            LinearKeyframe(distance, duration: 0.05)
            LinearKeyframe(-distance, duration: 0.1)
            LinearKeyframe(0, duration: 0.05)
        }
    }

    /// The same keyframes as a timeline, from rest.
    static var timeline: KeyframeTimeline<Double> {
        KeyframeTimeline(initialValue: 0.0) { keyframes }
    }

    /// The offset `seconds` after the shake starts.
    static func offset(at seconds: Double) -> Double {
        timeline.value(time: seconds)
    }

    /// How long the shake lasts, in seconds.
    static var duration: Double {
        timeline.duration
    }
}
